Squizzumables Changelog
=======================

V1.71

- Raid Tools, Reminders and Kelerts now have sub-tabs across the top, so each
  one is a screenful instead of a single long scroll. Raid Tools splits into
  General, Pull Timer, Scale, Battle Res, Target Distance and Position;
  Reminders into Class, Instance Sounds, Bags, Feast and Role CC; Kelerts into
  Lust Alert, Buff Sounds and Death Tally
- Search knows about them: a result now reads "Raid Tools > Pull Timer" and
  clicking it opens the right sub-tab as well as the right tab. Without that it
  would have jumped to the page and left the setting hidden behind an
  unselected sub-tab, which looks exactly like search being broken
- The headings and dividers that used to separate those sections are gone,
  since the sub-tab already names them
- New Target Distance readout: roughly how far away your target is, as movable
  on-screen text. Under Raid Tools, off by default. Choose whether it reads as a
  band ("30-35") or just one end of it, set the text size, alignment, colour and
  frame strata, and drag it into place with Unlock Frames like any other frame
- It reads as a band on purpose. The game gives addons no way to measure the
  distance to an enemy -- only to ask whether a particular spell or item would
  reach right now -- so the answer is worked out by asking a ladder of known
  ranges and reporting where you fall between two of them. Bands get wider
  further out, where there are fewer things to ask about
- The ladder is built mostly from your own spells, reading the ranges the game
  currently reports, so it follows talents that extend a spell's range without
  being told. A short list of fixed-range items fills the gaps your class leaves
  -- a melee spec has few long rungs and a caster few short ones
- Friendly targets are off by default and will often read "?" when switched on,
  since the estimate is built from harmful spells and items and those refuse to
  answer about a friendly unit
- Fixed a spell removed by a talent change vanishing from the Cooldown Manager
  and then reappearing a second later, with the group never shrinking around the
  gap. When a spell went away its icon was destroyed but left listed as a member
  of its group, and the next layout pass re-attached and re-showed the very frame
  that had just been destroyed. The clean-up only looked at spells you had
  assigned to a group by hand, so it missed everything relying on the standard
  Essential, Utility and Buffs groups -- which since 1.69 is almost everything.
  Groups also re-pack now, so the row closes up instead of holding the space
- Fixed the Cooldown Manager not updating on a spec or talent change until you
  reloaded. Three things were wrong, all introduced in 1.70. A spec change is
  handled in two places and each asked for a rebuild on its own timer; the
  shorter of the two cancelled the longer, so the rebuild ran while the game was
  still reporting the outgoing spec and then never ran again. Rebuilds are now
  never pulled earlier than one already waiting, so it no longer matters which
  order those arrive in
- The check for "have my cooldowns changed" was also looking only at Blizzard's
  filtered list, which updates on its own schedule, instead of the game's own
  set, which updates immediately. A talent swap could leave it looking identical
  and the rebuild was skipped entirely. Both are checked now -- one catches spec
  and talent changes, the other catches edits made in Blizzard's Cooldown
  Manager options, and neither alone covers both
- A talent or loadout swap now always rebuilds rather than trusting that check,
  matching what a spec change already did, since neither the game nor Blizzard's
  own list is necessarily up to date at the instant the event arrives
- The update notes popup now scrolls. With 1.70's eight highlights the text ran
  underneath the buttons and off the bottom of the box, leaving the last few
  unreadable and no way to reach them. The notes now sit in a scrolling area
  between the heading and the buttons, so however long a release's highlights
  are the box stays the same size and the buttons stay reachable
